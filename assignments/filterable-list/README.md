# Mint & Mango — completed filterable list

Original Kalvium Community menu data kept. Search is controlled, uses case-insensitive .filter(), renders .map() with key={item.id}, shows a friendly empty state, and restores items with Clear. TypeScript uses strict mode.

Run: npm install && npm run dev. Open http://localhost:3000. Test searches 'ma', 'PIZZA', and 'ZZZ-NOMATCH'.
